## 🌟 Executive Overview
Production-ready, ultra-fast, and responsive mobile developer portfolio for **Vivek Kumar Rai**. Designed with modern glassmorphism aesthetics, fluid micro-interactions, hardware-accelerated GSAP animations, 100% Google PageSpeed optimization, and an enterprise Schema.org JSON-LD SEO suite for top search rankings.

### ✨ Key Features
- **Modern Design System**: Sleek dark/light theme switching with smooth transitions and persistent state.
- **Hardware-Accelerated Motion**: 60–120 FPS animations powered by GSAP (3D card tilt, magnetic cursor, smooth section transitions).
- **Interactive Project Showcase**: Dynamic filtering ('All Projects' & 'Major Projects') with comprehensive modal dialogs.
- **System Architecture Visualizer**: High-resolution interactive lightbox for High-Level (HLD), Low-Level (LLD Clean Architecture), and Concurrency Resilience system diagrams.
- **SEO & Search Dominance**: Google Schema.org Knowledge Graph structured data, Open Graph social cards, XML sitemap, and crawler directives.
- **Zero Framework Bloat**: Pure HTML5, Vanilla CSS3, and ES6+ JavaScript for sub-second global load times.

## 🚀 Local Development

To run this portfolio locally without any external dependencies:

```bash
# Clone the repository
git clone https://github.com/VivekKumar620166/Portfolio.git
cd portfolio

# Run with Python built-in server
python3 -m http.server 8080

# Or run with Node.js npx serve
npx serve .
```

Open [http://localhost:8080](http://localhost:8080) in your browser.
